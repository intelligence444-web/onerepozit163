# Подключение Wordstat к облачной среде Claude

Ключ API никогда не присылается в чат — только в настройки среды.

## 1. Сеть
Настройки среды (меню облачной среды в шапке сессии → Edit) → «Доступ к сети» → добавить домен `searchapi.api.cloud.yandex.net`. Проверка из сессии: запрос без ключа возвращает 400/401 с JSON-ошибкой от Яндекса, а не 403 от прокси.

## 2. API-ключ в Yandex Cloud
1. AI Studio (console.yandex.cloud → AI Studio) → раздел Yandex Search API → кнопка «Создать API-ключ».
2. Описание — например «Wordstat для Claude»; срок — лучше 90 дней.
3. «Создать» → сразу скопировать ключ `AQVN…` (показывается один раз).
Яндекс сам создаёт сервисный аккаунт с нужными ролями. Если баланс 0 ₽ и запросы не идут — привязать платёжный аккаунт.

## 3. Сетевой секрет в среде Claude
Настройки среды → «Сетевые секреты» → добавить:
- Разрешённые сайты: `searchapi.api.cloud.yandex.net`
- Префикс пути: `/v2/wordstat/`
- Заголовок: `Authorization`, префикс `Api-Key` (не Bearer!), значение — сам ключ.

ID каталога (`b1g…`) обычно не нужен — ключ привязан к каталогу сервисного аккаунта. Если API попросит folderId — переменная среды `YC_FOLDER_ID` (ID виден в адресе console.yandex.cloud/folders/<id>).

Сохранить → новая сессия или перезапуск текущей.

## 4. Проверка
```
curl -sS -X POST https://searchapi.api.cloud.yandex.net/v2/wordstat/topRequests \
  -H "Content-Type: application/json" \
  -d '{"phrase":"лендинг под ключ","numPhrases":"5","regions":["225"]}'
```
Ответ с `totalCount` и `results` — всё работает. `Unknown api key` — неверный префикс/ключ. `IAM token or API key has to be passed` — секрет не подхватился (не та среда или не перезапущена сессия).
