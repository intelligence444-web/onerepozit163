# Kie.ai коннектор для claude.ai

Свой MCP-коннектор: в обычном чате claude.ai можно попросить «сделай баннер…», и Claude сам сгенерирует картинку или видео через Kie.ai.
Весь код в одном файле `worker.js`, он размещается бесплатно на Cloudflare Workers. Ничего устанавливать на компьютер не нужно.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `kie_balance` | показывает остаток кредитов |
| `kie_generate_image` | картинка (Nano Banana, Nano Banana Pro, Seedream, Flux), ждёт результат и даёт ссылку |
| `kie_generate_video` | видео Veo 3 (fast или quality), отдаёт task_id |
| `kie_create_task` | любая другая модель из каталога Kie (Kling, Hailuo, Wan…) |
| `kie_check_task` | статус задачи и ссылки на готовые файлы |

Ссылки на результаты Kie временные: готовые файлы лучше сразу скачивать.

## Установка (≈15 минут)

### 1. Cloudflare Worker
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. **Workers & Pages → Create → Start with Hello World**, имя `kie-mcp`, нажмите **Deploy**.
3. **Edit code**: удалите всё, вставьте содержимое `worker.js`, нажмите **Deploy**.

### 2. Переменные
В воркере откройте **Settings → Variables and Secrets → Add** и добавьте две переменные с типом **Secret**:

| Имя | Значение |
|---|---|
| `KIE_API_KEY` | ваш ключ из кабинета kie.ai |
| `MCP_SECRET` | придумайте длинную строку из латинских букв и цифр (30+ символов), это пароль коннектора |

Сохраните (**Deploy**).

### 3. Подключение в claude.ai
1. claude.ai → **Настройки → Коннекторы → Добавить свой коннектор**.
2. Название: `Kie`.
3. URL: `https://kie-mcp.<ваш-поддомен>.workers.dev/mcp/<MCP_SECRET>`. Адрес воркера показан на его странице в Cloudflare.
4. Поля OAuth оставьте пустыми и нажмите **Добавить**.

В чате включите коннектор Kie (кнопка инструментов под полем ввода) и попросите: «проверь баланс Kie».

## Безопасность
- Адрес коннектора с `MCP_SECRET` работает как пароль: тот, кто его знает, тратит ваши кредиты. Никому его не отправляйте.
- Если адрес утёк, поменяйте `MCP_SECRET` в Cloudflare и обновите URL коннектора.
- Ключ Kie хранится только в Cloudflare, в коде и в чате его нет.
