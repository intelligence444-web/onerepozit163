# Бриф для креативов в стиле ad-engine.ru

Источник: главная https://ad-engine.ru/ (`index.html`, `assets/main.css`). Креативы для рекламы услуги «клиенты на квартиры в новостройках» для застройщиков, агентств и риелторов.

## 1. Цвета

| Роль | HEX | Где на сайте |
|---|---|---|
| Акцент (изумрудный) | `#0e7c5a` | кнопки, подзаголовок, кикер, иконки |
| Акцент при наведении / тёмный | `#0a6247` | наведение кнопки |
| Тёмно-зелёный текст | `#11603a` | статусы |
| Мягкий акцент (фон плашек) | `#e2f3ec` | плашка над заголовком, выбранный ответ квиза |
| Светло-зелёный 2 | `#d6efe5`, `#dcf3e5` | статусы «Назначен показ» |
| «Онлайн»-точка | `#1fae5b` | «Отвечаю за 3 минуты» |
| Текст | `#15171a` | заголовки; он же фон тёмных блоков |
| Серый текст | `#5b616b` | подписи, лид |
| Фон светлых секций | `#f1f3f6` | чередующиеся блоки |
| Линии | `#dde1e7` | рамки карточек |
| Белый | `#ffffff` | основной фон |

Сияние на фоне («аврора»): размытые пятна `rgba(14,124,90,.2)`, бирюза `rgba(20,184,166,.14)`, салатовый `rgba(132,204,22,.10)`, справа от текста.

Чужие бренды в их цветах: Telegram `#229ed9`, MAX `#6b4cf5`, ссылки Яндекса `#1a0dab`. Красный `#c62828` только для ошибок, в креативах не использовать.

Пропорция: ~80% белый/светло-серый, ~15% чёрный текст, ~5% изумрудный (кнопка, одно выделение).

## 2. Шрифт

**Onest** (Google Fonts, бесплатный, кириллица). Файлы: `landengine/assets/fonts/onest-*.woff2`.

- Заголовок: Bold 700, межбуквенный −3,5%, интерлиньяж 1.05. Пример: «Клиенты на квартиры в новостройках».
- Подзаголовок: SemiBold 600, изумрудный, интерлиньяж 1.3.
- Цифры фактов: Bold 700, −2%.
- Текст и подписи: Regular 400, серый `#5b616b`.
- Логотип: «**AD** ENGINE» — AD жирным, ENGINE тонким 300, разрядка 8%.

## 3. Форма и элементы

- Скругления: карточки 16–20 px, кнопки 8 px, плашки-кикеры полностью круглые (999 px).
- Кнопка: изумрудная заливка, белый текст SemiBold 16, высота 52 px. На сайте есть блик, пробегающий по кнопке (для видео-креативов).
- Карточки: белые, рамка `#dde1e7` 1 px, мягкая тень снизу `0 24px 48px -32px rgba(21,23,26,.35)`.
- Плашка над заголовком: фон `#e2f3ec`, текст изумрудный SemiBold.
- Номера шагов: изумрудный кружок с белой цифрой.
- Тёмный блок: фон `#15171a`, белый текст, белая кнопка.
- Фон: светлый, справа зелёное сияние и полупрозрачный силуэт многоэтажек (`assets/skyline.svg`).

## 4. Графика

- Логотип-знак: `landengine/assets/logo-mark.png` (зелёные треугольники).
- 3D-иконки в изумрудной гамме, белый фон, мягкий свет, глянцевый пластик (`assets/3d/`):
  `house` (многоэтажка с меткой), `target` (мишень), `funnel` (воронка), `calc` (калькулятор), `audit` (планшет с лупой), `report` (отчёт с графиком), `lupa` (лупа и рост), `search` (поисковая строка), `shield` (щит с галочкой), `phone` (заявки в телефоне), `video` (телефон с видео), `laptop` / `support` (ноутбук), `people` (аудитория), `gift` (подарок), `faq` (вопросы).
- Фото автора: `landengine/assets/founder.webp`.
- Главный визуальный приём сайта — «путь заявки»: три карточки по шагам 1 → 2 → 3 (объявление в Директе → квиз «Какой бюджет на покупку?» с выбранным «6–9 млн» → заявка в CRM со статусом «Назначен показ») и всплывающие уведомления «+ Новая заявка». Хорошо подходит для креативов и анимации.

Промпт-основа для генерации 3D в том же стиле:
> 3D icon of {объект}, glossy soft plastic, emerald green #0e7c5a and mint #e2f3ec with white details, soft studio lighting, pure white background, minimal, clean, centered, no text

## 5. Тексты (подтверждённые факты)

- Заголовок: **Клиенты на квартиры в новостройках**
- Подзаголовок: Комплексный маркетинг в недвижимости: лиды по новостройкам под ключ
- Над заголовком: Лиды для застройщиков, агентств и риелторов
- Цифры: **от 30 заявок** в месяц на проект · **от 700 ₽** цена заявки · **5–45 млн ₽** чек квартир · **13 лет** в интернет-маркетинге · **5+ лет** в недвижимости
- Площадки: Яндекс Директ, Авито Реклама, VK Реклама
- Тезисы: «Считаем показы и сделки, а не клики»; «Берём на себя всё: от создания лендинга до сквозной аналитики»; заявки сразу в CRM; защита от ботов и спама; отчёты на понятном языке.
- Путь заявки: Клик → Заявка → Квалифицированный лид → Показ объекта → Сделка.
- Сегменты: Застройщики / Агентства недвижимости / Риелторы.
- Офферы и кнопки: «Рассчитать стоимость лида в вашем городе», «Бесплатный аудит рекламы», «Проверить мою рекламу», «Смотреть видео в MAX» (видео 7 мин, кейсы, отзывы).
- Подарок за договор в течение 3 рабочих дней: оформление группы ВКонтакте, фотосессия объекта или автообзвон по базе.
- Работа по договору с ИП.
- Контакты: 8 (927) 011-11-60, «Отвечаю за 3 минуты»; бот MAX https://max.ru/id633067457803_bot; сайт ad-engine.ru.

Нельзя: выдумывать кейсы, отзывы, цифры и имена клиентов. Писать «риелтор» через «е». Площадки — «Яндекс Директ», «Авито Реклама», «VK Реклама».

## 6. Готовые форматы (рекомендация)

| Площадка | Размер | Что внутри |
|---|---|---|
| VK Реклама, лента | 1080×1080, 1080×1350 | заголовок + 1 цифра + 3D-дом + кнопка |

| Яндекс Директ (РСЯ) | 1080×607 (16:9), 1080×1080, 600×900 | заголовок слева, 3D справа, логотип в углу |

| Авито Реклама | по требованиям кабинета | крупная цифра «от 700 ₽ за заявку» |

Сетка: поля 6–8% по краям, текст слева, визуал справа, как на первом экране сайта. Не больше трёх уровней текста на одном креативе.
